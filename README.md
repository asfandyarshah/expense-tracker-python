Personal Expense Tracker (Python)

A command-line app that records income and expenses, sorts them into categories, and shows monthly summaries. Data is saved to a JSON file, so it is still there next time you run the program.

Features

	•	Add income and expenses with amount, category, date, and an optional note
	•	View all records in a table, sorted by date
	•	Monthly summary: total income, total expenses, net savings, and spending by category with percentages
	•	Delete a record by ID
	•	Input validation, so invalid amounts or dates do not crash the program

Requirements

	•	Python 3.8 or newer (no extra libraries needed)

How to run

python expense_tracker.py

Choose an option from the menu (1-6). Your data is stored in expenses.json in the same folder.

What I practised

Functions, dictionaries and lists, JSON file handling, input validation, string formatting.
